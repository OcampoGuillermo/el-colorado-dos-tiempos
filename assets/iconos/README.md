# Íconos del centro de juegos

Esta carpeta contiene las **10 imágenes cuadradas** que aparecen en [`hub.html`](./../hub.html) como botones de acceso a los proyectos de El Colorado.

## Estado actual

Los archivos son **placeholders generados automáticamente** (cuadradas con color, inicial y lema). No son fotos hiperrealistas.

## Cómo reemplazar con fotos hiperrealistas

1. Conservá el **nombre exacto** de cada archivo.
2. Usá imágenes **JPG cuadradas**, idealmente **900 × 900 px** o más.
3. Copiálas en `assets/iconos/` sobreescribiendo los placeholders.
4. No es necesario tocar `hub.html` ni reconstruir nada.
